Who Am I

I'm a Full-Stack Developer with proven experience in web and mobile application development using JavaScript, React, Next.js, Vue.js, TypeScript, PHP (Laravel), and Java. I specialize in building end-to-end applications from requirements analysis through to deployment.

My expertise includes developing e-commerce platforms, digital library systems, IoT monitoring solutions, and database-driven applications. I'm accustomed to working in collaborative team environments and am committed to writing scalable, testable code that meets deadlines. Currently seeking opportunities to contribute to high-quality application development, particularly in remote working environments.
